## Ultimate Calculator

A scientific, algebra and calculus calculator for Android, built entirely on a phone by Abdalla Said Ahmed.

### Install
1. Download the `.apk` file below under **Assets**.
2. Open it and tap **Install** (allow installs from this source if Android asks).
3. If Play Protect warns you, choose **Install anyway**.

Requires Android 5.0 or newer on a 64-bit (arm64) phone. Works offline.

See the [README](https://github.com/abdallasaidbigpartner-web/Calculator#readme) for features and examples, and the [CHANGELOG](https://github.com/abdallasaidbigpartner-web/Calculator/blob/main/CHANGELOG.md) for what is new.
