# Changelog

All notable changes to this project are listed here.

## [1.0.0] - 2026-11-15

First full release.

### Added
- Scientific calculator with brackets, percent, Ans, UNDO, 2nd key, DEG/RAD and fraction/decimal display
- Variables x, y, z, A, B, C with STO, and memory keys
- Algebra: solve equations, expand, factor and simplify polynomials, symbolic derivative and integral
- Calculus: numeric derivative, definite integral, limits, sums and products
- Complex numbers, number theory, bitwise operations and base conversion
- Matrices, vectors, statistics and probability distributions
- Unit conversion and physics constants
- Graph and table of values for formulas in x
- Calculation history, apps menu and creator banner
- Automatic APK build and GitHub Release publishing

## [0.1.0] - 2026-11-14

- First prototype: a simple four-function calculator used to prove the phone-only build pipeline.
